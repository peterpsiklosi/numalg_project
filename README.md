# Final Project for the Introduction to Numerical Algorithms class
Made by Majoros Bernát & Siklósi Péter Pál

THREE-BODY PROBLEM USING EULER'S METHOD, LEAPFROG AND RUNGE-KUTTA INTEGRATION

Our project is about the n-body problem, simulating and visualizing an n-body system in 2D using different numerical methods, such as Euler's method and Leapfrog integration. Our goal is to show how each numerical solver can tackle this famous problem and why some work and others do not. We also want to show an example of a stable 3/4-body system such as our Solar System.
